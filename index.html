    How to use this in CS2
    
Paste the output into the console, or save it as autoexec.cfg in game/csgo/cfg/ (add exec yourfile if you use a separate file). Press the bound key repeatedly: each press sends the next line, then loops back to line 1 after the last one. If you press partway and want to restart, re-exec the config.

    
Notes: CS2 has no wait, so spam filters are avoided by pressing manually. Double quotes can't be nested inside an alias, and // is read as a comment start in cfg files, so avoid those in your text. Chat message length limits vary, and Braille characters take 3 bytes each in UTF-8, so long art lines may get truncated in game. Tune the byte limit warning to what you observe.
